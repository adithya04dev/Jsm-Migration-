# PagerDuty to Jira Service Management — Peer Review Handoff

This repository is a **presentation preparation handoff**, not an implementation repository. It contains a high-level, public-safe outline for explaining a migration from PagerDuty to Jira Service Management (JSM).

## Context
- Motivation: the existing PagerDuty license was approaching expiry.
- Goal: migrate alerting and on-call workflows to JSM.
- Topics documented for the peer review: Grafana contact point, routing critical alerts, on-call schedules, escalation policies, documentation, and validation.
- Validation was confirmed as completed in the preparation conversation; exact test evidence is not included here.
