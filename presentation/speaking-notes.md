# Speaking cues — not a memorized script

## Opening
"Today I'll walk through the PagerDuty-to-JSM migration: why it was needed, what we configured, how we validated it, and what remains."

## Problem
- PagerDuty license approaching expiry
- Need to preserve alerting and on-call response
- Transition to JSM

## Implementation
- Grafana contact point and critical alert routing
- On-call schedules and escalation policies
- Documentation and team readiness

## Validation
- Explain only the tests actually performed
- Use internal evidence during an approved demo
- Separate completed items from remaining actions

## Close
"That covers the motivation, implementation, and validation. I'm happy to take questions on the integration and operational flow."

## Rehearsal technique
For each slide: **Point → Explain → Example → Transition**.
Use 2–3 keywords, not a paragraph-length script. Rehearse once with notes, once using only cues, and once as an uninterrupted run-through. If you lose your place, pause and return to the slide's main point.
